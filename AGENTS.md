# Repository instructions

Read and follow [VELOCITY.md](VELOCITY.md) when creating, selecting, implementing,
commenting on, or closing RabbitHole issues.

- Track actionable work in the RabbitHole workspace and `RH` team in Velocity.
- Post issue comments when meaningful work is completed, including validation
  evidence, commit links, and any remaining work.
- Mark an issue Done only after its acceptance criteria are satisfied, its
  changes are committed and pushed, and CI verifies the final pushed changes
  as described in VELOCITY.md.
- Preserve unrelated working-tree changes and keep commits scoped to the task.
